# Inmorpho Portfolio

Портфолио-сайт Inmorpho: AI-креатор (фешн-видео, нарративные ролики) с заделом под будущий раздел дизайна интерьеров.

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger — скролл-анимации
- Lenis — плавный скролл

## Разработка

```bash
npm install
npm run dev
```

## Структура

- `/` — главная, направление AI-видео
- `/interiors` — заглушка под будущий раздел интерьеров
